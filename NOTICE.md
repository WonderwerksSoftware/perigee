# Perigee notices

Perigee is a modified remote-streaming client.

## Source base and dependencies

- [Moonlight Qt](https://github.com/moonlight-stream/moonlight-qt) is the client source base. Perigee preserves its source history, notices, and GNU GPL version 3-or-later license.
- [Moonlight Common C](https://github.com/moonlight-stream/moonlight-common-c) supplies the streaming protocol implementation. Its source and license remain in `moonlight-common-c/moonlight-common-c`.
- Other bundled libraries and submodules retain their own source notices and licenses. Those notices apply in addition to this file.

The complete GNU General Public License, version 3, is in `LICENSE`.

## Integration and reference projects

- [Polaris](https://github.com/papi-ux/polaris) is the enhanced host integration target. A companion fork contains the server-side work.
- [Artemis](https://github.com/wjbeckett/artemis) supplied user-experience and feature-inventory inspiration only. This statement does not claim Artemis code provenance.
- [Nova](https://github.com/papi-ux/nova) was a Polaris protocol and behavior reference only. This statement does not claim Nova code provenance.

The Polaris companion changes are maintained separately. They are not part of the Perigee client source tree.
